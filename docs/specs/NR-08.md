# NR-08 — Durable scheduler и fake backend

Статус: PLANNED. Фаза: Core. Зависимости: [07](NR-07.md).

## Цель

Получить полностью воспроизводимый offline lifecycle и основу ограниченного параллелизма.

## Входы и границы

Читать [PRODUCT](../PRODUCT.md), [ARCHITECTURE](../ARCHITECTURE.md), [runtime protocol](../protocols/RUNTIME.md), [development protocol](../protocols/DEVELOPMENT.md) и [DoD](../DEFINITION_OF_DONE.md). Входы: current main SHA, подтверждённое lead назначение, merged evidence зависимостей, spec hash. Если реализация уже частично существует, сначала проверить её и закрывать разницу с ТЗ, а не переписывать.

## Работы

1. Реализовать ReviewerBackend interface и deterministic fake backend для success/finding/error/partial/delayed/unknown-send.
2. Создать durable очередь jobs/attempts, leases/fencing, global semaphore и fairness по review.
3. Ввести deadline, bounded retry с backoff/jitter и error classification; zero retry для policy/auth ошибок.
4. Собрать offline vertical slice submit → snapshot → runs → provisional deterministic aggregation → status; provisional этап явно не претендует на semantic validation live.

## Контракт и ограничения

Default global concurrency 3; один слот на каждый активный backend turn, включая adjudication/verification. Run identity != attempt identity. Fake помечен во всех reports.

## Критерии приёмки

- **NR-08-AC1**: Concurrency никогда не превышает config; две очереди progress без starvation.
- **NR-08-AC2**: Retry не создаёт duplicate accepted finding, late result не меняет terminal cycle.
- **NR-08-AC3**: Fake complete/no-findings может пройти offline gate; malformed/missing run никогда не APPROVED.
- **NR-08-AC4**: Offline demo воспроизводит finding и cancellation без сети/ChatGPT.

## Проверки и evidence

- Virtual clock tests lease expiry, retries, fairness, cancel race.
- Real DB restart: queued jobs возвращаются, stale fencing token отвергается.
- Приложить команды, exit codes, environment/версии, exact SHA и hashes артефактов. Live-проверки отмечать LIVE, deterministic FAKE/CONTRACT; не подменять одно другим.
- Связать каждый AC с доказательством в PR. Общие проверки — только существующие команды из package scripts; после NR-01 обязательно `bun run verify`.

## Не входит

Не выдавать fake pass за live qualification; нет эвристического majority approve.

## Сбои, риски и откат

Unknown send → reconciliation, не blind resend. Rollback pause queue, дождаться/отозвать leases, оставить events.

# NR-09 — Production bridge adapter

Статус: PLANNED. Фаза: Web MVP. Зависимости: [02](NR-02.md), [08](NR-08.md).

## Цель

Заменить spike устойчивым backend для настоящих ChatGPT turns.

## Входы и границы

Читать [PRODUCT](../PRODUCT.md), [ARCHITECTURE](../ARCHITECTURE.md), [runtime protocol](../protocols/RUNTIME.md), [development protocol](../protocols/DEVELOPMENT.md) и [DoD](../DEFINITION_OF_DONE.md). Входы: current main SHA, подтверждённое lead назначение, merged evidence зависимостей, spec hash. Если реализация уже частично существует, сначала проверить её и закрывать разницу с ТЗ, а не переписывать.

## Работы

1. Реализовать adapter по доказанному NR-02 wire contract и pinned upstream version.
2. Обработать HTTP/SSE streaming, actual completion, correlation, fresh-session identity и observed model/effort.
3. Сохранить raw before parse, typed transport failures, bounded schema repair и abort/cancel cleanup.
4. Добавить compatibility health check и отказ при неподдерживаемом bridge; подготовить upgrade canary.

## Контракт и ограничения

execute/capabilities/cancel контракт ARCHITECTURE.md. Partial stream не success. Адаптер владеет только собственными tabs/requests; обычные пользовательские чаты не закрывает.

## Критерии приёмки

- **NR-09-AC1**: Один live reviewer возвращает schema-valid результат, raw и receipt связаны с exact run/SHA.
- **NR-09-AC2**: SSE disconnect/ambiguous completion не приводят к дублированной отправке.
- **NR-09-AC3**: Неверная модель/effort/bridge версия дают явный blocker.
- **NR-09-AC4**: Cancel освобождает owned resources; late completion audit-only.

## Проверки и evidence

- Recorded contract tests для chunk boundaries, malformed JSON, timeout, error frames.
- Live smoke одного complete и одного cancelled turn с artifacts.
- Приложить команды, exit codes, environment/версии, exact SHA и hashes артефактов. Live-проверки отмечать LIVE, deterministic FAKE/CONTRACT; не подменять одно другим.
- Связать каждый AC с доказательством в PR. Общие проверки — только существующие команды из package scripts; после NR-01 обязательно `bun run verify`.

## Не входит

Read-only MCP roundtrip production уровня завершается NR-10; не копировать browser automation во все слои.

## Сбои, риски и откат

UI drift → BACKEND_UNAVAILABLE с diagnostics. Rollback на предыдущий verified bridge pin, без silent model fallback.

## Поставка

Один bounded PR `[NR-09] Production bridge adapter` в `main`, включающий код, релевантные тесты, документацию поведения/миграции и evidence index. Пройти reviewer → fix verification → lead merge authorization по точным SHA. После merge проверить resulting main и отправить TASK_COMPLETED. Если lead разбивает задачу, все child PR проходят тот же цикл, родитель завершается только после всех AC. Открытый PR не означает выполненное ТЗ.
